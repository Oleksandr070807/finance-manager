# REST API проєкту FinanceManager

Базова адреса: `http://localhost:3000/api`

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
|---|--------|-------|-------------|-------|---------|
| 1 | `/accounts` | GET | перелік усіх рахунків користувача | 200 | 500 |
| 2 | `/accounts/:id` | GET | інформація про конкретний рахунок | 200 | 404 |
| 3 | `/accounts` | POST | створення нового рахунку | 201 | 400, 422 |
| 4 | `/categories` | GET | перелік категорій доходів/витрат | 200 | 500 |
| 5 | `/transactions` | GET | перелік транзакцій із фільтрацією та пагінацією | 200 | 400 |
| 6 | `/transactions/:id` | GET | детальна інформація про транзакцію | 200 | 404 |
| 7 | `/transactions` | POST | створення нової транзакції | 201 | 400, 422 |
| 8 | `/transactions/:id` | PUT | повне оновлення транзакції | 200 | 404, 422 |
| 9 | `/transactions/:id` | DELETE | видалення транзакції | 204 | 404 |
| 10 | `/budgets` | GET | перелік місячних бюджетів | 200 | 500 |
| 11 | `/budgets/:id` | PATCH | часткове оновлення ліміту бюджету | 200 | 404, 422 |

## Параметри GET /transactions
| Параметр | Тип | Приклад | Опис |
|----------|-----|---------|------|
| `account_id` | int | `?account_id=1` | фільтр за конкретним рахунком |
| `category_id` | int | `?category_id=3` | фільтр за категорією |
| `type` | enum | `?type=expense` | тип транзакції (`income` або `expense`) |
| `q` | string | `?q=apple` | пошук за описом чи назвою |
| `page` | int | `?page=2` | номер сторінки пагінації |
| `limit` | int | `?limit=10` | кількість записів на сторінку |
